# 3D-Speaker 双人音频 API 测试

测试源为 3D-Speaker 官方 `2speakers_example.wav`，16kHz、单声道，参考
RTTM 包含 2 位说话人、5 个交替轮次，共 50.72 秒有效语音。

## 使用参考换人边界提交

- 参考说话人数：2
- API 聚类人数：2
- 标签映射：`speaker_00 -> 1`，`speaker_01 -> 2`
- 五段预测序列：`00, 01, 00, 01, 00`
- 时长加权说话人准确率：100%
- 非空转录率：100%
- 总处理时间：约 12.21 秒

该结果证明 CAM++ 嵌入和在线聚类能够在已知语句/换人边界下稳定区分并复用两位
说话人的标签。这里没有参考逐字稿，因此不能计算 CER，只能人工查看转录文本。

## 整段音频只在末尾提交

- 流式 partial：86 次
- 最终说话人数：1
- 最终标签：`speaker_00`
- 总处理时间：约 12.43 秒

当前 API 把一次 `commit` 定义为一个说话人语句，因此整段提交不会自动发现内部换人。
这说明现有服务的转录与说话人聚类有效，但完整的服务端说话人变化检测/长音频
diarization 仍需继续接入。
